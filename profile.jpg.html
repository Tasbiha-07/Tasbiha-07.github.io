About Me

Hello! I am Tasbiha Desai, a computer science engineering student specializing in Artificial Intelligence and Machine Learning at AGMR College of Engineering & Technology, Karnataka.

I am driven by a fundamental curiosity for turning complex datasets into reliable, transparent engineering systems. Instead of treating machine learning as a black box, I focus on the underlying mechanics—fine-tuning retrieval pipelines, handling heavy class skew in classification tasks, and building intuitive natural language interfaces using modern LLM APIs.

My recent projects range from building hybrid RAG search architectures with Reciprocal Rank Fusion, to orchestrating conversational sales analytics tools using the Gemini API, to crafting end-to-end interactive applications. I value clean code structure, modular architecture, and tangible problem solving.
